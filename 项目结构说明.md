# 实习生交流平台 - 项目结构说明

## 技术栈
- 前端：React + TypeScript + Zustand（状态管理）+ TailwindCSS
- 后端：Node.js + Express + Socket.io
- 数据库：MongoDB + Redis（缓存/验证码）
- 文件存储：本地 uploads 目录（后期可接 OSS）

---

## 目录结构

```
shixi chat/
├── frontend/                        # 前端项目
│   ├── public/                      # 静态资源
│   └── src/
│       ├── pages/                   # 页面（路由级组件）
│       │   ├── auth/                # 登录 / 注册 / 验证码
│       │   ├── forum/               # 论坛首页、行业分类、帖子详情
│       │   ├── chat/                # 私聊页面
│       │   ├── profile/             # 个人主页
│       │   ├── search/              # 搜索页面
│       │   └── group/               # 群组聊天页面
│       ├── components/              # 可复用组件
│       │   ├── auth/                # 登录表单、注册表单、验证码输入框
│       │   ├── forum/               # 帖子卡片、评论区、发帖弹窗
│       │   ├── chat/                # 消息气泡、输入框、文件上传
│       │   ├── profile/             # 信息卡片、编辑表单
│       │   ├── search/              # 搜索栏、搜索结果列表
│       │   ├── group/               # 群成员列表、创建群弹窗
│       │   └── common/              # 导航栏、侧边栏、头像、加载动画等公共组件
│       ├── store/                   # 全局状态（用户、聊天、论坛）
│       ├── api/                     # 封装所有后端接口请求
│       ├── utils/                   # 工具函数（时间格式化、文件处理等）
│       ├── styles/                  # 全局样式
│       └── assets/
│           ├── icons/               # 图标
│           └── images/              # 图片

├── backend/                         # 后端项目
│   ├── config/                      # 数据库连接、环境变量配置
│   ├── uploads/                     # 上传文件存储
│   │   ├── avatars/                 # 用户头像
│   │   └── files/                   # 聊天文件
│   └── src/
│       ├── controllers/             # 业务逻辑控制层
│       │   ├── auth/                # 注册、登录、验证码、JWT
│       │   ├── forum/               # 论坛分类、帖子 CRUD、评论
│       │   ├── chat/                # 私聊消息、历史记录
│       │   ├── user/                # 好友增删查、个人信息修改
│       │   └── group/               # 群组创建、成员管理
│       ├── models/                  # 数据库模型（User/Message/Post/Group等）
│       ├── routes/                  # 路由注册
│       ├── middleware/              # JWT验证、权限校验、文件上传中间件
│       ├── services/                # 邮件/短信验证码服务等
│       ├── socket/                  # Socket.io 实时通信（私聊、群聊、在线状态）
│       └── utils/                   # 加密、工具函数

└── docs/                            # 接口文档、设计文档
```

## 功能模块对照

| 功能         | 前端页面/组件              | 后端模块                  |
|------------|------------------------|------------------------|
| 用户登录注册   | pages/auth             | controllers/auth       |
| 验证码       | components/auth        | services/ + Redis      |
| 职业论坛     | pages/forum            | controllers/forum      |
| 好友聊天     | pages/chat             | controllers/chat + socket |
| 文件发送     | components/chat        | middleware/upload      |
| 个人主页     | pages/profile          | controllers/user       |
| 搜索        | pages/search           | 复用 user/forum 接口     |
| 群组        | pages/group            | controllers/group + socket |
